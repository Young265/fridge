3) H/W 주요 기능 3. 주요 적용 기술
기능/부품 설명 프로젝트실물사진
1. 음성 인식 (STT: Speech-to-Text)
적용 기술: Flutter STT
적용 목적: 저시력자가 마이크 버튼 클릭 없이도 앱 실행 시 바로 음성으로 명령 전달
가능
이론 기반: 음성의 파형을 MFCC 등으로 추출하여 음성 신호 → 문자로 변환
적용 방식:
Flutter 앱에서 speech_to_text 패키지를 사용해 실시간 녹음
Flask 백엔드로 STT 결과 전달 → Rasa로 intent 분석
2. 음성 합성 (TTS: Text-to-Speech)
적용 기술: Flutter TTS
적용 목적: 시각적 정보 제공이 어려운 저시력자에게 제품 정보, 요약 등을 음성으로
안내
이론 기반: Tacotron2 + WaveNet 기반 딥러닝 합성 모델
적용 방식:
Rasa → Flask → Flutter 순으로 챗봇 응답 전송
flutter_tts 패키지를 통해 자연스러운 음성 출력 구현
3. 자연어 처리 및 대화 흐름 관리 (NLU/NLG)
적용 기술: Rasa 2.x
적용 목적: 상품 탐색, 장바구니 조작, 정보 요약 등 음성 명령을 인식하고 응답
이론 기반:
