I. 프로젝트 개요 가. 프로젝트 소개

주제영역 ☑ 생활 □ 업무 □ 공공/교통 □ 금융/핀테크 ㅇ 식재료 자동 인식 및 관리 기능 제공

□ 기타 ( )
수행기간 2026. 4. 1. ~ 2026. 10. 30. ㅇ 독거노인의 식재료 관리 어려움 해결 필요
최근 고령화로 인해 독거노인의 수가 증가하면서 식재료 관리와 식사 준비에 어려움을 겪는
ㅇ 음식물 폐기 문제 감소 필요
사례가 늘어나고 있다. 냉장고에 어떤 식재료가 있는지 제대로 파악하지 못해 식재료를
활용하지 못하거나 음식물 낭비가 발생하는 문제도 존재한다.
프로젝트 소개 이를 해결하기 위해 본 프로젝트에서는 AI 기반 식재료 인식 기술을 활용한 스마트 냉장고 ㅇ 스마트홈 기반 생활 지원 서비스 확대 필요
및 제안배경 시스템을 개발하고자 한다. 냉장고 내부 카메라로 식재료 이미지를 촬영하고 AI가 이를
인식하여 보유 식재료를 확인할 수 있도록 하며, 해당 식재료를 활용한 레시피를 추천한다.
이를 통해 독거노인의 식재료 관리 부담을 줄이고 보다 편리한 식생활을 지원하는 스마트
주방 서비스를 제공하는 것을 목표로 한다.
• 카메라 기반 식재료 자동 인식 기능
• 식재료 데이터 자동 저장 및 관리 기능
주요기능
• 보유 식재료 기반 레시피 추천 기능
• 모바일 또는 웹 기반 냉장고 관리 기능
• 인공지능 이미지 인식 기술 (CNN 기반 객체 인식)
• 카메라 기반 이미지 데이터 수집
적용 기술 • 데이터베이스 기반 식재료 관리 시스템
• 웹 또는 모바일 인터페이스 기반 사용자 서비스
• IoT 기반 스마트 디바이스 연동 기술
예상 결과물
• 독거노인의 식재료 관리 부담 감소
기대효과 및 • 식재료 관리로 음식물 폐기 감소
활용 분야 • 스마트 홈 기반 식생활 관리 서비스 확장 가능
• 복지 서비스 및 스마트 헬스케어 분야 활용 가능
